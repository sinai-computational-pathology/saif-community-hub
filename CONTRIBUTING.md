# Contributing to the Hypothesis Explorer

Use GitHub Discussions to propose a hypothesis, add supporting or conflicting literature, or offer an alternative explanation. Identify the organ and demographic target, link the relevant result, and explain what each source supports and what remains uncertain.

Community submissions remain separate from the study-linked candidates on the site. Maintainers review scientific changes before updating the published data. Source support does not establish that the model uses a proposed feature.

Use Issues for broken links, incorrect content, and accessibility or website defects. Pull requests should describe the proposed correction and include supporting evidence. Run `npm run check` for site changes.

Do not post patient identifiers, restricted data, private paths, credentials, or full copyrighted articles. Everything submitted here is public.
