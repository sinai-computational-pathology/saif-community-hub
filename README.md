# Hypothesis Explorer

A static companion to the [Results Atlas](https://sinai-computational-pathology.github.io/saif-results-atlas/), presenting Skin/self-reported race, Breast/age-group, and Gastric/sex candidates with literature and limitations.

The candidates remain proposed; source support does not establish model reliance. Community discussion is separate from these study-linked candidates.

Build and check with `npm run check`. The build consumes the packaged `data/signals.json` and `data/viewer_hypotheses.json`. These are generated upstream; do not independently edit their numbers or citations here.

The current release does not publish historical hypothesis snapshots. They remain archived in the authoring repository.
