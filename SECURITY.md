# Security and sensitive-data reporting

Do not open a public issue containing credentials, protected health information, patient identifiers, restricted data, private infrastructure details, or unpublished sensitive results.

For a potential security or privacy problem, use GitHub's private vulnerability reporting when available or contact a repository maintainer privately through their verified institutional channel. Include only the minimum information needed to locate the problem.

The public site is static and has no application database, custom authentication, upload surface, or browser-writable scientific review store.
